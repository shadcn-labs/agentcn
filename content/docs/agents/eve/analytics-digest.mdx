## Summary

**Analytics Digest** is an agent that pulls key event trends from PostHog and creates a weekly digest summarizing product usage patterns. It queries event data, identifies top events by volume, computes week-over-week changes, detects notable trends, and composes a concise digest with actionable recommendations.
