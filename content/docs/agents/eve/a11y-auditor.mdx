## Summary

**Accessibility Auditor** is an agent that audits project pages for WCAG violations using axe-core via the sandbox CLI. It receives URLs to audit, runs axe against each page, de-duplicates and groups violations by rule ID and impact level, and files GitHub issues for verified violations.
