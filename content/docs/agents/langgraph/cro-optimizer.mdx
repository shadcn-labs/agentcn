## Summary

The **CRO Optimizer** identifies drop-offs in user funnels and proposes data-backed experiments. It quantifies the impact of each drop-off point, analyzes possible causes using session data, proposes specific testable experiment hypotheses, and estimates expected lift based on industry benchmarks. Creates structured experiment briefs ready for execution.
