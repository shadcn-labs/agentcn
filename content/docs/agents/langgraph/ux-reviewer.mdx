## Summary

The **UX Reviewer** analyzes user interfaces for usability issues. It navigates through user flows and identifies UX problems, focusing on usability heuristics, accessibility, visual hierarchy, consistency, and user error prevention. Provides specific, actionable improvement suggestions with priority levels.
