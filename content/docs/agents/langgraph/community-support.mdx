## Summary

The **Community Support** agent helps maintainers respond to Discord support requests efficiently. It fetches recent Discord messages, classifies issue types (bug, feature request, question, feedback), assesses urgency based on user impact, drafts responses with troubleshooting steps, and flags messages needing immediate attention.
