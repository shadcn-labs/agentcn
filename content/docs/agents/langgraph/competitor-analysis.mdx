## Summary

The **Competitor Analysis** agent monitors competitor websites for meaningful changes. It detects pricing changes, new features or product announcements, changes to positioning or messaging, and updates to integrations or partnerships. When material changes are detected, it sends concise alerts to a designated Slack channel.
