## Summary

The **A11y Auditor** helps teams ship WCAG-compliant experiences by running axe-core audits against project pages. It classifies violations by severity (critical, serious, moderate, minor), provides concrete fix recommendations, and files GitHub issues for verified violations. Focuses on WCAG 2.1 AA compliance with emphasis on keyboard navigation, screen reader compatibility, and color contrast.
