## Summary

The **Dependency Guardian Agent** scans project dependencies for known vulnerabilities, license compliance issues, and outdated packages. It generates prioritized upgrade recommendations with risk assessments and migration guides.

## Customization

- **Swap the model.** Edit `config.ts`.
- **Modify instructions.** Edit `instructions.md`.
- **Adjust memory.** Edit `memory.ts`.
