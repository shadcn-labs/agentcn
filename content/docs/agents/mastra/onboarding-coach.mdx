## Summary

The **Onboarding Coach Agent** personalizes the onboarding experience by adapting guidance based on user background, goals, and progress. It provides contextual tips, celebrates milestones, and helps users reach their "aha moment" faster.

- **Modify instructions.** Edit `instructions.md`.
- **Adjust memory.** Edit `memory.ts`.
