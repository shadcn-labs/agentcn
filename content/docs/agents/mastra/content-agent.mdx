## Summary

The **Content Agent** transforms briefs into polished content pieces. It researches topics, structures outlines, drafts copy, and refines based on brand voice guidelines. Supports multiple content formats including blog posts, landing pages, and social media copy.

## Customization

- **Swap the model.** Edit `config.ts`.
- **Modify instructions.** Edit `instructions.md`.
- **Adjust memory.** Edit `memory.ts`.
