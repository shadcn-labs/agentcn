## Summary

The **Release Notes Agent** analyzes git commits, PRs, and issue references to generate structured changelogs. It categorizes changes by type (features, fixes, breaking changes) and writes user-friendly release notes.

## Customization

- **Swap the model.** Edit `config.ts`.
- **Modify instructions.** Edit `instructions.md`.
- **Adjust memory.** Edit `memory.ts`.
