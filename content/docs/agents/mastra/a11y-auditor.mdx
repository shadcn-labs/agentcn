## Summary

The **Accessibility Auditor Agent** evaluates a web page against WCAG 2.1 guidelines, identifying issues like missing alt text, insufficient color contrast, keyboard navigation problems, and ARIA misconfigurations. It generates a structured report with severity levels and actionable remediation steps.
