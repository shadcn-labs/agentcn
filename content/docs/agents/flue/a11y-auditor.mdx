## Summary

The **Accessibility Auditor** scans project pages for WCAG violations using
axe-core. For each verified issue it files a GitHub issue with a clear
description, the relevant WCAG criterion, and reproduction steps. Reach for it
to keep your UI compliant without manual audits.
