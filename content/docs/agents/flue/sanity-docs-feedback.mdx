## Summary

The **Sanity Docs Feedback Agent** reviews Sanity documentation for accuracy,
completeness, and clarity. It navigates documentation pages with the browser,
identifies outdated information, missing examples, and confusing explanations,
then provides structured feedback with specific improvement suggestions.
