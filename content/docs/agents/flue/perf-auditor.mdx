## Summary

The **Performance Auditor** measures URL performance using PageSpeed Insights and
identifies issues that violate performance budgets. It analyzes Core Web Vitals
(LCP, INP, CLS), files GitHub issues for violations, and provides actionable
recommendations for improvement.

## Customization

- **Set budgets.** Adjust performance thresholds in the agent instructions.
- **Add more metrics.** Extend `run-pagespeed.ts` to capture additional data.
- **Swap the model.** Edit `agents/perf-auditor.ts`.
