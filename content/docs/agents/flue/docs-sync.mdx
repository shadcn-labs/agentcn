## Summary

The **Docs Sync Agent** keeps documentation current with recently merged code. It
uses the gh CLI to list merged PRs since the last docs update, identifies changes
that affect public APIs or user-facing behavior, and drafts docs PRs with the
necessary updates. PRs touching exported functions, CLI flags, or config schemas
are flagged as high priority.
