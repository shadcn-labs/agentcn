## Summary

The **UX Reviewer** uses agent-browser to inspect web interfaces and evaluate
usability, accessibility, visual hierarchy, consistency, and user flow. It
identifies friction points, confusing navigation, and accessibility violations,
then provides prioritized, actionable improvement suggestions with rationale.
