## Summary

The **Error Copy Agent** navigates your app with agent-browser to find vague,
unhelpful, or inconsistent error messages. It opens GitHub issues with specific
file paths, current copy, and suggested replacements. Errors shown to unpaid
users and onboarding flows are prioritized.
