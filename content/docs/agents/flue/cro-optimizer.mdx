## Summary

The **CRO Optimizer** analyzes conversion funnels using PostHog data and
inspects landing pages with agent-browser. It finds conversion drop-offs,
identifies friction points, and files experiment hypotheses with clear success
metrics, estimated impact, and implementation notes.
