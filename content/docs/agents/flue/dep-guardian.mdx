## Summary

The **Dependency Guardian** triages dependency update PRs and security alerts. It
uses the gh CLI to list open Dependabot/Renovate PRs, evaluates risk by checking
changelogs and breaking changes, and opens upgrade PRs for critical security
fixes. Each PR is summarized with a recommendation: merge, review, or hold.
