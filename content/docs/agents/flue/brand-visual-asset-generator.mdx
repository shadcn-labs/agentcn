## Summary

The **Brand Visual Asset Generator** turns a company domain into a coherent pack
of brand-aligned SVG visual assets. It pulls brand colors, typography, logos, and
product context from Context.dev, plans an asset pack (icons, empty states, hero
illustrations, badges, feature graphics, onboarding visuals, changelog art, and
dashboard or modal visuals), then calls `generate_svg_with_arrow` once per
finalized brief. The Quiver Arrow tool uses `quiverai/arrow-1.1` through Vercel
AI Gateway and returns editable SVG markup. The agent scores every asset against
quality and taste references, regenerating any that feel generic or off-brand,
and delivers a cohesive set with shared palette, stroke language, and geometry.

## Customization

- **Brand data source.** Brand context is pulled through
  [Context.dev](https://context.dev) — set `CONTEXT_DEV_API_KEY` (and optionally
  `CONTEXT_API_KEY` as a fallback). Edit `tools/context-dev-search.ts` to swap
  the API endpoint or add more Context.dev tools.
- **SVG generation.** `generate_svg_with_arrow` uses `quiverai/arrow-1.1` through
  Vercel AI Gateway — set `AI_GATEWAY_API_KEY` or `VERCEL_OIDC_TOKEN`. Edit
  `tools/generate-svg-with-arrow.ts` to swap the image model or adjust reference
  image handling.
- **Pack defaults.** Edit `skills/brand-visual-assets/references/default-pack.md`
  to change which assets are generated when the user asks for a "visual pack"
  without listing items.
- **Quality bar.** Tune `references/quality-bar.md` and `references/scorecard.md`
  to raise or lower the acceptance threshold for generated assets.
- **Swap the model.** Edit `agents/brand-visual-asset-generator.ts` —
  `deepseek/deepseek-v4-pro` for orchestration. Any capable model works.
